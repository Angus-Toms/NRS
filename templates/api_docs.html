Overview

All endpoints live under /api/v1 and return JSON. Endpoints marked CSV also accept ?format=csv and respond with a downloadable file. Times are raw seconds with a formatted h:mm:ss companion field; dates are ISO 8601. Data refreshes weekly after each ratings rebuild, and responses are cacheable for an hour.

The data is free for non-commercial use with attribution. Results and data are provided by World Triathlon and the PTO; Pro Tri Data is in no way affiliated with either. Please cite Pro Tri Data and link back when you publish anything built on this API. Every JSON payload carries source, license, and attribution fields restating this.

Endpoints
GET /api/v1/athletes/{athlete_id}

Bio, current ratings, and world/national rankings for an athlete.

  • category - elite (default) or ag
  • course - short (default) or long
curl "https://www.protridata.com/api/v1/athletes/96742?course=short"
GET /api/v1/athletes/{athlete_id}/results

Full race history with splits and behind-leader times. CSV supported.

  • category - elite (default) or ag
  • course - short (default) or long
  • format - json (default) or csv
curl "https://www.protridata.com/api/v1/athletes/96742/results?format=csv" -O -J
GET /api/v1/athletes/{athlete_id}/ratings

Rating history over time, per discipline, one row per race. CSV supported.

  • category - elite (default) or ag
  • course - short (default) or long
  • format - json (default) or csv
curl "https://www.protridata.com/api/v1/athletes/96742/ratings"
GET /api/v1/races/{race_id}

Race info plus the field-strength standard per discipline.

curl "https://www.protridata.com/api/v1/races/1185917170"
GET /api/v1/races/{race_id}/results

Full results for a race with splits and behind-leader times. CSV supported.

  • format - json (default) or csv
curl "https://www.protridata.com/api/v1/races/1185917170/results?format=csv" -O -J
GET /api/v1/leaderboard

Current leaderboard, mirroring the site's leaderboard filters. Capped at 200 rows per request. CSV supported.

  • gender - male or female (default)
  • disc - overall (default), swim, bike, run, transition
  • order - top (default, by rating) or hot (by 1-year change)
  • country - full country name, or all (default)
  • yob_start / yob_end - year-of-birth range, 1930 to 2010
  • active_only - true (default) limits to athletes who raced in the last 18 months
  • category - elite (default) or ag
  • course - short (default) or long
  • limit - rows per request, 1 to 200 (default 50)
  • offset - pagination offset (default 0)
curl "https://www.protridata.com/api/v1/leaderboard?gender=male&disc=run&limit=100"
Notes
  • Unknown athlete or race ids return a 404.
  • There is no authentication and no hard rate limit; please be considerate and cache responses on your side.
  • Data refreshes weekly, so polling more than once a day gains nothing.
